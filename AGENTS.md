# MediaDocks Development Guidelines

## Project Overview
MediaDocks is a high-performance, privacy-focused universal media downloader web application built with Next.js App Router, React 19, Tailwind CSS, and Prisma.

## Key Principles
- **Privacy & Security**: Zero permanent storage of downloaded media. All media streams are processed ephemerally in memory and piped directly to the client.
- **Performance**: 60 FPS animations, lightweight responsive UI, and optimized multi-rung stream extraction.
- **Code Quality**: Strict TypeScript types, unit and integration tests for all extractors and API endpoints.
